# Operations Runbook

## Daily Operations

### Health Check

```sql
-- Platform status at a glance
SELECT
    (SELECT COUNT(*) FROM RAW.DOCUMENT_REGISTRY) AS TOTAL_DOCS,
    (SELECT COUNT(*) FROM RAW.DOCUMENT_REGISTRY WHERE PROCESSING_STATUS = 'FAILED') AS FAILED_DOCS,
    (SELECT COUNT(*) FROM RAW.DOCUMENT_REGISTRY WHERE PROCESSING_STATUS = 'PENDING') AS PENDING_DOCS,
    (SELECT COUNT(*) FROM KNOWLEDGE.DOCUMENT_CHUNKS) AS TOTAL_CHUNKS,
    (SELECT COUNT(*) FROM AGENT.CONVERSATIONS WHERE STATUS = 'ACTIVE') AS ACTIVE_CONVERSATIONS;
```

### Task Status

```sql
-- Check task execution history
SELECT NAME, STATE, SCHEDULED_TIME, COMPLETED_TIME, ERROR_MESSAGE
FROM TABLE(INFORMATION_SCHEMA.TASK_HISTORY(
    SCHEDULED_TIME_RANGE_START => DATEADD('HOUR', -24, CURRENT_TIMESTAMP()),
    TASK_NAME => 'DOCUMENT_INGESTION_TASK'
))
ORDER BY SCHEDULED_TIME DESC
LIMIT 20;
```

### Dynamic Table Refresh Status

```sql
SELECT NAME, TARGET_LAG, REFRESH_MODE, LAST_COMPLETED_REFRESH, DATA_TIMESTAMP
FROM TABLE(INFORMATION_SCHEMA.DYNAMIC_TABLE_REFRESH_HISTORY(
    NAME_PREFIX => 'CORTEX_AI_PLATFORM.KNOWLEDGE'
))
ORDER BY LAST_COMPLETED_REFRESH DESC;
```

## Common Operations

### Reprocess Failed Documents

```sql
-- Reset failed documents for retry
UPDATE RAW.DOCUMENT_REGISTRY
SET PROCESSING_STATUS = 'PENDING', RETRY_COUNT = 0, ERROR_MESSAGE = NULL
WHERE PROCESSING_STATUS = 'FAILED'
  AND RETRY_COUNT >= 3;
```

### Remove a Document from Knowledge Base

```sql
-- Remove all traces of a document
SET DOC_ID = 'your_document_id';

DELETE FROM KNOWLEDGE.DOCUMENT_CHUNKS WHERE DOCUMENT_ID = $DOC_ID;
DELETE FROM KNOWLEDGE.KNOWLEDGE_CATALOG WHERE DOCUMENT_ID = $DOC_ID;
DELETE FROM PROCESSED.DOCUMENT_METADATA WHERE DOCUMENT_ID = $DOC_ID;
DELETE FROM PROCESSED.DOCUMENT_CLASSIFICATIONS WHERE DOCUMENT_ID = $DOC_ID;
DELETE FROM PROCESSED.PARSED_DOCUMENTS WHERE DOCUMENT_ID = $DOC_ID;
DELETE FROM RAW.DOCUMENT_REGISTRY WHERE DOCUMENT_ID = $DOC_ID;
```

### Add a New Department

1. Create the stage:
```sql
CREATE STAGE IF NOT EXISTS RAW.NEW_DEPT_DOCS DIRECTORY = (ENABLE = TRUE);
```

2. Create the role:
```sql
CREATE ROLE CORTEX_AI_NEW_DEPT;
GRANT ROLE CORTEX_AI_NEW_DEPT TO ROLE CORTEX_AI_USER;
```

3. Add to role-department mapping:
```sql
INSERT INTO GOVERNANCE.ROLE_DEPARTMENT_MAP (ROLE_NAME, DEPARTMENT)
VALUES ('CORTEX_AI_NEW_DEPT', 'new_dept'),
       ('CORTEX_AI_ADMIN', 'new_dept'),
       ('CORTEX_AI_SERVICE', 'new_dept');
```

4. Update `config/platform.yaml` with the new department entry.

### Suspend Platform (Cost Savings)

```sql
-- Suspend all tasks
ALTER TASK RAW.DOCUMENT_INGESTION_TASK SUSPEND;
ALTER TASK RAW.DOCUMENT_RETRY_TASK SUSPEND;

-- Warehouses auto-suspend, but force if needed:
ALTER WAREHOUSE CORTEX_AI_INGESTION_WH SUSPEND;
ALTER WAREHOUSE CORTEX_AI_SEARCH_WH SUSPEND;
```

### Resume Platform

```sql
ALTER TASK RAW.DOCUMENT_INGESTION_TASK RESUME;
ALTER TASK RAW.DOCUMENT_RETRY_TASK RESUME;
-- Warehouses auto-resume on demand
```

## Monitoring Queries

### Token Cost (Last 7 Days)

```sql
SELECT
    DATE_TRUNC('DAY', HOUR_BUCKET) AS DAY,
    MODEL,
    SUM(INVOCATION_COUNT) AS INVOCATIONS,
    SUM(TOTAL_TOKENS) AS TOKENS,
    SUM(ESTIMATED_COST_USD) AS COST_USD
FROM OBSERVABILITY.COST_AGGREGATION
WHERE HOUR_BUCKET > DATEADD('DAY', -7, CURRENT_TIMESTAMP())
GROUP BY DAY, MODEL
ORDER BY DAY DESC, COST_USD DESC;
```

### Search Quality

```sql
SELECT
    DATE_TRUNC('DAY', CREATED_AT) AS DAY,
    COUNT(*) AS SEARCHES,
    AVG(TOP_SCORE) AS AVG_RELEVANCE,
    AVG(LATENCY_MS) AS AVG_LATENCY_MS,
    COUNT(CASE WHEN TOP_SCORE < 0.5 THEN 1 END) AS LOW_QUALITY_SEARCHES
FROM OBSERVABILITY.SEARCH_DIAGNOSTICS
WHERE CREATED_AT > DATEADD('DAY', -7, CURRENT_TIMESTAMP())
GROUP BY DAY
ORDER BY DAY DESC;
```

### Guardrail Violation Trends

```sql
SELECT
    DATE_TRUNC('DAY', CREATED_AT) AS DAY,
    VIOLATION_TYPE,
    COUNT(*) AS VIOLATIONS
FROM GOVERNANCE.AI_GOVERNANCE_LOG
WHERE EVENT_TYPE = 'GUARDRAIL_VIOLATION'
  AND CREATED_AT > DATEADD('DAY', -30, CURRENT_TIMESTAMP())
GROUP BY DAY, VIOLATION_TYPE
ORDER BY DAY DESC;
```

## Incident Response

### Cortex Search Service Down

1. Check service status: `SHOW CORTEX SEARCH SERVICES IN SCHEMA KNOWLEDGE;`
2. If offline, recreate: Re-run `sql/cortex_search/001_create_service.sql`
3. Fallback: Vector similarity search activates automatically in Python service

### Ingestion Pipeline Stuck

1. Check stream: `SELECT SYSTEM$STREAM_HAS_DATA('RAW.DOCUMENT_REGISTRY_STREAM');`
2. Check task: `SELECT * FROM TABLE(INFORMATION_SCHEMA.TASK_HISTORY(...));`
3. Manual process: `CALL RAW.PROCESS_DOCUMENT_PIPELINE('doc_id');`

### High Token Cost

1. Review cost DT: `SELECT * FROM OBSERVABILITY.COST_AGGREGATION ORDER BY HOUR_BUCKET DESC;`
2. Identify expensive model: Switch classification from sonnet to haiku
3. Reduce chunk overlap or increase chunk size in config
4. Suspend non-critical tasks during off-hours
